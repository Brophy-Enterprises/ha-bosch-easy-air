# ha-bosch-easy-air
Home Assistant Integration for Bosch Easy Air Thermostats. BCC110 specifically. Not affiliated with Bosch.

Custom Component for allowing Home Assistant to control your BCC110 Bosch thermostat. Built for myself using entirely vibe coding, so use at your own risk. Works for me though.


Originally inspired by [pszafer/home-assistant-bosch-custom-component](https://github.com/bosch-thermostat/home-assistant-bosch-custom-component) so go and check that out, it might fit your needs better
